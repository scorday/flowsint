# Локальная приёмка Flowsint в AVL4 — 2026-10-16

Локальная установка выполнена в каноническом `avl4-local-app`, профиль `flowsint`.
Новые отдельные PostgreSQL/Neo4j volumes, Alembic head `e4f5a6b7c8d9` и constraint
`avl4_material_identity`. Данных самостоятельной установки для переноса нет.
API, worker, UI и обе базы healthy; initializer завершён с кодом 0.

## Повторение установки и проверки

[Инструкция локального стека](../../../../AVLTEAM/projects/avl4-monorepo-py/avl-deploy/avl4.localhost/FLOWSINT.md)
описывает `make init`, `config-flowsint`, `up-flowsint`, smoke helper,
резервирование и отключение интеграции с сохранением данных.
Секреты и cookies находятся только в игнорируемых приватных файлах локального стека.

Проверка выполнялась с настоящими Keycloak OAuth, Auth-сессиями, Redis,
PostgreSQL, Neo4j, Cards и браузером, без подмены ответов API.
Созданы два синтетических проекта и обычный участник только первого проекта.
Четыре пустых проекта от неуспешных подготовительных попыток помечены удалёнными
через публичный Auth API; рабочие приёмочные проекты и карточки сохранены.

Auth публикует снимки проектов по существующему 60-секундному циклу.
Проверка доступа использует последний опубликованный снимок публичного клиента;
отзыв административной операцией не мгновенный. Helper ждёт до 90 секунд
для отказа и отдельно для восстановления доступа.
